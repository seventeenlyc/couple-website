# 拾光隔离样例 RAG 设计

日期：2026-10-04。阶段：已确认范围，待审阅本规格；尚未实施 RAG 产品代码。

## 目标和范围

先用独立数据库与虚构数据验证“提问 → 检索 → 有依据的回答 → 打开来源”，检索共同相册与手工故事时间线。私密随笔、私密文件、悄悄话不进入索引。真实业务库为空时不能拿样例补成用户记忆。

已验证 Google 项目 `claude-495107` 的 ADC、768 维向量生成、Gemini 回答。NT$300/月预算提醒已存在；赠金实际抵扣仍待账单核对。后续没有创建托管云数据库的需求。

## 方案选择

| 方案 | 优点 | 代价 | 决定 |
|---|---|---|---|
| 本地 SQLite 索引 + Vertex AI 向量/回答 | 沿用 Node/SQLite；测试隔离容易；没有常驻云数据库费用 | 小数据集由后端计算余弦相似度 | 采用 |
| Google 托管 RAG/向量检索 | 托管索引与扩展 | 额外费用、生命周期和权限配置 | 数据规模增长时再评估 |
| 只增强现有关键词查询 | 实施简单 | 无法充分验证语义检索 | 保留为受约束降级，不作为 RAG 主链路 |

## 隔离与运行方式

- 实施前创建隔离工作区并保留当前大量未提交修改；以工作区当前内容作为基线，不重置、不提交无关文件。
- 使用独立 `server/data/rag-demo/couple.db`，初始化现有业务表和新增 RAG 表。启动命令明确指定该库，禁止种子脚本使用主库默认路径。
- 演示运行在 `127.0.0.2:19085`，保留现有 `127.0.0.1:19085` 服务。现有前端在非 19085 端口会回退到原服务，不能直接换端口而误向原服务写入。
- 隔离实例允许自身 Origin，并使用独立工作区的静态资源和测试图。不能仅设置 `rootDir` 就假定静态目录改变：当前 app.js 的静态根目录取自模块目录。
- 样例账号用独立测试身份和密码，仅作用于演示库。每个回复包含 `isExample=true`，页面显示“隔离样例”；线上 RAG 默认关闭。
- 不读取真实照片，不上传图片本体；只向 Vertex 发送当前样例的描述和问题。后续接真实数据另行确定数据上传范围。

## 统一记忆与索引

来源事实保留在 `album_photos`、`story_events`。第一版不索引 getStoryTimeline 自动生成的周年和照片上传汇总，避免重复召回或把系统文案当作手工记忆。

独立 RAG 表记录：

| 字段 | 含义 |
|---|---|
| memory_id / source_type / source_id | 稳定索引身份和真实来源身份；source_type 只允许 photo/story |
| corpus_id | 当前测试情侣的共同记忆语料；服务端确定，不接受客户端自行指定 |
| title / text | 标题、照片说明或故事正文组成的可检索文本 |
| province / city / place / location_aliases | 显式元数据，样例中人工声明；完整地点不能任意截成前两字 |
| event_date / date_kind | 故事为事件日期；相册无拍摄日期时为上传日期并明确标记，不伪装成拍摄日期 |
| source_hash / indexed_at | 识别来源更新和同步时间 |
| embedding / embedding_model / dimensions | 768 维向量、模型和维数；模型/维数不同的向量禁止混算 |

一条照片一个片段；短故事一个片段，长故事按段落组合分片，初始上限 800 字、重叠 100 字。同一故事的多片段最后按来源 ID 去重。原图和缩略图路径从来源表回查，不由模型生成。

种子与重建命令可重复执行；未变更的文本复用向量，变化后重算，删除来源时删索引。索引更新在事务中完成，调用失败不会留下标为完成的残缺索引。

## 查询与生成

1. 验证登录和共同语料访问权；样例用户只访问演示 corpus。无法确定共同语料归属时拒绝检索，不能把所有用户的数据合并。
2. 解析结构化查询：完整地点实体、日期范围、来源类型、语义文本。采用 Gemini 结构化输出，结合样例地点/别名表验证；保留原始地点提及，未知、冲突或含糊地点不默认映射成别的城市。省市连写拆成省份与城市，修饰语不作为实体。
3. 日期明确时转成完整区间；“去年”以服务端当前日期解析。日期解析失败需要澄清，不能悄悄删除限制。照片回答必须说明日期类型。
4. 在 SQLite WHERE 中按 corpus、类型、地点、日期过滤后再计算余弦相似度。关键词和向量分别形成候选，再以 reciprocal rank fusion 合并，来源去重后最多给模型 3 条。不复用现有无条件实体前缀回退。
5. 有符合限制的候选也不一定相关：用验收问题评估相似度和排名差距，选择并记录初始阈值；不预设一个未经验证的通用阈值。低置信度明确提示相近候选；候选为空直接由服务端回答未找到，不请求模型编造记忆。
6. 回答模型只读取通过约束的证据。把记忆正文作为数据，忽略正文内的指令。结构化返回正文与证据 ID；服务端拒绝候选集合之外的 ID，并从真实来源构造引用、日期与路径。模型拒绝、超时或输出不合法时展示确定性的证据摘要，不宣称模型生成成功。

## 接口与双端引用

- 保留 `/api/agent/chat` 和 `/api/agent-chat.php` 的响应兼容性：success、reply、companion、source、memoryRef、draft。
- 演示开关启用且为找回忆意图时走 RAG；留言与约会草稿继续现有路径。主服务未启用时行为不变。
- 新增 `memoryRefs`（多来源）、`retrievalStatus`（exact/related/not_found/clarify/error）和 `isExample`；memoryRef 保留第一条，供兼容消费。
- 当前双端卡片点击一律打开照片查看器，不能假定故事引用已经可点击阅读。实现时增加按 type 分流：photo 打开现有原图查看器；story 通过受鉴权的来源读取接口打开只读正文弹窗，必要时同时展示故事配图。
- 来源读取再次检查 corpus 与身份；不能凭一个 ID 就读取其他语料。动态文字用 textContent 或现有 HTML 转义，事件使用闭包，不把自由文本放入内联 JavaScript。

## 模型、成本与凭据

- Vertex 项目沿用 `claude-495107`；embedding 用 `gemini-embedding-001`（RETRIEVAL_DOCUMENT/RETRIEVAL_QUERY 对应任务类型，768 维）；生成和查询解析用已验证的 `gemini-3.1-flash-lite`。
- Node 客户端使用 ADC；密钥和访问令牌不入仓库，不逐请求调用 gcloud。
- 向量按文本 hash 缓存；最多索引 16 条短样例；询问解析与最终回答限制输入长度和输出 tokens。演示验收设模型请求次数上限 100，并记录实际请求数与 tokens；到达上限停止演示模型请求，避免无限重试。
- 不创建 Spanner、托管向量数据库、虚拟机或自动轮询任务。预算提醒不是硬停费；实际赠金抵扣另核对。

## 验收

| 条件 | 必须验证的结果 |
|---|---|
| 明确厦门/上海/成都 | 引用地点符合请求 |
| 只有厦门，查询成都 | 未找到，无错误城市引用 |
| 只有四川绵阳，查询四川成都 | 未找到，不能放宽成四川 |
| 成都、和田、太原、个旧、从化 | 完整地点保留；不存在时不得返回其他城市 |
| 九月旧照片 + 五张十月新照片 | 九月查询仍能找到旧照片 |
| 去年照片，当前年为 2026 | 日期范围为 2025 年 |
| “吹晚风看太阳落下” | 无标题字面一致仍可召回相关海边日落记录 |
| 滑雪、潜水等完全不存在的主题 | 无引用，明确未找到 |
| 多条相似记录 | 来源去重，正文与引用一致 |
| story 无图片 | 打开原故事正文，不打开空照片查看器 |
| 注入文本、记忆内指令 | 不执行脚本、不改变系统行为 |
| 私密表有独特探针文本 | 不索引、不检索、不发送给云模型 |
| 索引重建、文本更新、来源删除 | 幂等、变化重算、旧引用失效 |
| 模型失败、额度上限 | 返回明确降级状态，无假成功 |
| 演示库与原服务 | 原服务数据库不变；样例回复可辨识 |

验证分层：单元测试验证过滤、身份、索引和失败处理；真实 Vertex 样例验证语义检索；独立 Fastify HTTP 验证接口；实际浏览器验证双端照片和故事来源点击。使用桩的测试、真实模型、真实页面、生产部署分别报告；不把它们合并为笼统“全量验收”。
