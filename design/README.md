## 2. 独立浏览器交互原型 (`design/mobile-prototype/index.html`)

### 2.1 运行方式
- 本原型为**纯前端无依赖实现**（零外部 CDN、零构建步骤、零生产接口调用）。
- 双击或在任意现代浏览器中打开 `design/mobile-prototype/index.html` 即可运行体验。

### 2.2 包含的核心功能与画板覆盖（M01 ~ M12）
1. **多设备视口模拟（规范 5.1 节）**：
   - **390px (标准参考)**：针对 iPhone 14/15 视口，验证核心边距（20px）、图文排版。
   - **360px (紧凑验证)**：针对安卓紧凑屏，验证 16px 边距与文字防折行。
   - **430px (大屏验证)**：针对 Pro Max / Plus 宽屏，验证留白比例。
   - **响应式模式**：自适应窗口尺寸。
2. **M01 日常（流动影集）**：
   - 顶部站点名称与“＋”记录入口。
   - 单张核心展签大图（保留原始比例、展签说明排版：“那天没有计划，只是一起走了很远。”、日期与“在一起第 520 天”）。
   - 克制来信提示条：“有一封给你的信 · 打开 ↗”（无多余角标与红点）。
   - 双列照片故事章节：“九月的几个瞬间”。
   - 独立轻文字展签：“今日一句”。
3. **M02 空状态与异常切换**：
   - 原型顶部控制器支持一键切换 M02 状态：“这里还没有照片。记录我们的第一张吧。”。
4. **M03 相册**：
   - 面包屑路径层级：`全部 / 2026年 / 厦门旅行`。
   - 文件夹胶囊横滑栏与照片计数。
   - 标签分类筛选（全部、风景、美食、抓拍）。
   - 4:5 比例双列照片网格与图下展签说明。
5. **M04 全屏大图查看器**：
   - `#181716` 深炭色沉浸背景。
   - 点击任意照片即可展开查看原图，支持关闭、张数计数（2 / 12）与底部展签。
6. **M05 & M06 上传与异常恢复**：
   - 首页“＋”唤出底部操作面板（发照片 / 记故事 / 写悄悄话）。
   - 上传页面支持目标目录切换、已选文件列表。
   - 呈现 1 成功、1 上传中（带实时字节进度 `1.8 MB / 2.6 MB (69%)`）、1 网络中断失败项。
   - 严格遵循规范 M06：提供针对失败项的单项“重试”按钮，保留已成功项，不产生重复提交。
7. **M07 心愿与任务状态机**：
   - 两个清晰入口：“任务与签到”、“小铺与礼物”（杜绝仪表盘卡片）。
   - 签到打卡按钮与连续打卡计数。
   - 严格符合任务状态机：完成者仅显示“等待对方确认”（无自我确认）；合法确认者执行“确认完成发放奖励”。
8. **M08 小铺与积分兑换**：
   - 积分余额清晰显示在此页（不在首页或顶栏泄露）。
   - 礼物双列网格（拥抱券、按摩券、免洗碗券等）。
   - 兑换二次确认弹窗与扣减反馈。
9. **M09 我们与故事时间线**：
   - 双方头像、昵称（小林 & 小鹿）、相伴天数。
   - 重要纪念日与生日倒数。
   - 故事时间线（2026 编年时间轴节点）。
10. **M10 来信全屏阅读**：
    - 温暖质感纸张排版、完整发送信息、归档反馈。
11. **M11 私密空间**：
    - 4 位 PIN 独立密码锁键盘。
    - 解锁后查看专属私密随笔与留存信件，支持随时“立即锁定”。
12. **M12 设备与授权**：
    - 展示当前设备授权状态。
    - 模拟新设备接入审批、核对码验证（`7392-A8`）与倒计时。

## 3. Figma 导入与矢量画板说明 (`design/artboards/`)

在 `design/artboards/` 目录下生成了 3 套高精度 SVG 矢量画板，专为导入 Figma 进行二次编辑而设计：

1. **`M01-daily-gallery.svg`**：
   - 尺寸：390 × 844 px。
   - 包含完整的日常流动影集、展签排版、信件提示条、双列网格与底部 4 栏导航。
2. **`M03-album.svg`**：
   - 尺寸：390 × 844 px。
   - 包含面包屑路径、文件夹胶囊行、标签过滤与双列 4:5 照片流。
3. **`M05-upload.svg`**：
   - 尺寸：390 × 844 px。
   - 包含目标目录选择、上传列表、字节进度条、失败项单独重试按钮及底部主按钮。

### 如何导入 Figma：
1. 打开 Figma 客户端或网页版工作台（新建空白设计文件）。
2. 将 `design/artboards/` 中的 `.svg` 文件**直接拖拽到 Figma 画布**中。
3. Figma 将自动解析为原生 **Frame、矢量图层（Vector）、文本图层（Text）与分组（Group）**，所有颜色（`#F7F5F1`, `#883E4A`, `#252422` 等）均已对齐设计规范变量。

## 5. 生产级移动端 H5 应用 (`h5/`)

为满足真实移动设备（微信、手机浏览器、PWA 全屏模式）下的最佳体验，开发了专用的 H5 应用：

```text
h5/
├── index.html           # 移动端 H5 主入口页面 (真机 100% 视口贴合 + 状态栏/Home条安全区适配)
├── css/
│   └── gallery-h5.css   # H5 专用样式系统 (色彩变量、展签排版、触控反馈、手势过渡)
└── js/
    ├── api-client.js    # 数据通信层 (支持真实后端 API 与离线 LocalStorage 双模持久化)
    └── app.js           # 页面交互总控 (四栏路由、全屏大图、原生文件上传、PIN 码锁、Agent交互等)
```

- **访问方式**：
  - 本地直开：双击打开 `h5/index.html`；
  - Node 服务访问：`http://<IP>:19085/h5`（由 `server/src/compat/gateway-routes.js` 统一托管）。

## 6. AI 专属伴侣「拾光」Agent 入口与能力体系

为情侣双方预留并构建了专属情感与记忆伴侣——**「拾光」**：

1. **核心定位**：
   - 🧠 **记忆档案**：记住相恋天数（520天）、纪念日（04.30）、生日、偏好、生活习惯与相册故事。
   - 💬 **情感倾听与解忧**：小摩擦换位思考、破冰台词生成、情绪抚平。
   - 🎁 **约会与惊喜策划**：基于双方喜好的轻生活约会灵感。
   - 💌 **信件与留言辅助**：协助把难以开口的话写成温柔的书信，支持一键存入「私密信箱」或「故事时间线」。
2. **三大多维入口**：
   - **顶栏常驻入口**：顶栏右上角微光星芒图标 ✨，随时一键唤起；
   - **生活流日常入口**：日常页“今日一句”下方解忧卡片；
   - **「我们」核心卡片**：主服务卡片「专属伴侣 · 拾光 Agent」。
3. **后端 API 支持**：
   - `POST /api/agent/chat` (或 `/api/agent-chat.php`)；
   - 服务端位于 `server/src/modules/ai/ai.service.js` 中的 `chatWithCoupleAgent(db, message, history)`，支持连接大语言模型，并具备高共情力的规则备份引擎。
